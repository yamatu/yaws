# v0.2.0

Machine-specific egress monitoring and a remote SSH coding workspace.

- Ping runs on the selected authenticated Agent, with machine-scoped targets, persistent samples, latency/jitter/loss charts and explicit offline/upgrade states.
- SSH adds machine shortcuts, host fingerprint verification, bounded terminal buffers and session revocation.
- SFTP supports product directory discovery, directory browsing, upload/download, UTF-8 configuration/source editing, revision conflicts and backups.
- AI supports custom Chat Completions or Responses endpoints, model/reasoning settings, directory read tools, file diffs, individually approved changes/commands and saved task history.
- Security fixes include database-backed role/session validation, password-change revocation, WebSocket origin checks without tokens in URLs, protected initial bootstrap, encrypted AI data, endpoint address validation and dependency updates.

## Upgrade

Update the controller and Agent together. Agents older than v0.2.0 cannot run the new Ping protocol. Existing controller-based monitors are migrated to paused, unassigned records; recreate them for a selected machine. The Agent needs a working system `ping` utility.

Existing SSH credentials remain encrypted and reusable, but SSH now requires reviewing and trusting each machine's host fingerprint. New installations in production also require `BOOTSTRAP_TOKEN` for initial administrator creation; existing administrators are unaffected.

Models must support tool calls. The reasoning value is passed through and must be supported by the chosen provider. AI integration is validated with compatible local test endpoints; no production model credentials or live customer servers are used during tests.

Validation: TypeScript, production build, Node security/integration tests, Go test/vet and Linux amd64/arm64 builds, desktop/mobile Edge browser checks, npm audit (zero reported vulnerabilities).
