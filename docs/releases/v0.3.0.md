# v0.3.0

Model Context Protocol, streamed answers, extension packages and one-click Agent installation.

- MCP servers can be added from the panel (stdio command or Streamable HTTP), with encrypted environment variables and headers, a per-server test button and per-server fault isolation: a server that fails to start only loses its own tools.
- AI answers stream in as they are produced (thinking, text, tool calls and token usage), parsed from the provider's SSE stream for both Chat Completions and Responses protocols; the final full-text event is still emitted for compatibility.
- The chat page shows prompt cache hits next to the token usage, and distinguishes "the provider reported zero cached tokens" from "the provider said nothing".
- Extension packages add tools, skills, prompts and guards. Packages are installed from a git URL or a local directory, run in-process with the panel's permissions, and are rolled back when they contribute nothing; a guard that throws never fails a run.
- Several conversations can run the model at the same time (8 per user, 32 per panel); a single conversation stays exclusive and answers 409 while it is busy, and a panel at its limit answers 429 instead of queueing silently.
- The Agent can be installed on a machine straight from the panel over the SSH connection the workspace already uses, with a domestic (Gitee first) and an overseas (GitHub first) order; both fall back to the panel itself, so a host that can reach the panel can always finish.
- The panel serves the Agent builds it ships (`agent/bin`, also copied into the Docker image) at `/api/agent/binary/<asset>` and verifies downloads against `SHA256SUMS` when one is published.

## Upgrade

Update the controller and the Agent together. Agent v0.3.0 reports its version, so the installer skips a re-download when the host already runs the version the panel ships (`--check` reports, `--force` reinstalls).

New optional controller settings: `AGENT_GITEE_REPO` and `AGENT_GITEE_RELEASE_BASE_URL` for the domestic mirror, `AGENT_BINARY_DIR` for the Agent builds the panel hands out, and `AGENT_RELEASE_TAG` to pin a release (Gitee has no `latest` alias, so without it the installer asks the Gitee API for the newest tag).

Extension packages are trusted code: install them only from sources you control. MCP servers reach the network on behalf of the model; review the command or URL before mounting one.

Validation: TypeScript, production build, Node security/integration/MCP/extension/concurrency/installer tests, Go test/vet and Linux amd64/arm64 builds.
